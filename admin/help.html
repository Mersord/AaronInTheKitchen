THE EVERYDAY ROUTINE

From an idea to a recipe.

Open Recipes and choose an existing recipe or New Recipe. Start with the name, visibility, category and introduction. Add the yield, times and media, then ingredients and cooking steps. Advanced menu-name and display-order fields are at the bottom.

Use the existing filter menu to show a category or visibility state. Ingredient groups and steps keep Decap's expand, collapse and reorder controls.

Changing an existing recipe's title does not intentionally rename its file in this setup. Duplicating creates another entry: give it a distinct title and check its new address before relying on it.

INGREDIENTS & AMOUNTS

Fractions welcome.

Measured ingredient amount fields now accept 0.5, 0,5, 1/2, ½, or 1 1/2. Fractions are saved as ordinary numbers, so the website's conversion code keeps working. The helper line shows the decimal when useful.

Use one group for a simple recipe, or separate Cake, Filling and Frosting. Existing recipes retain their formatted ingredient text. For the same ingredient, use either the formatted text or a measured row, not both.

Display after step usually stays at 0. Imported recipes can intentionally put later frosting or topping ingredients after a cooking step. That order is retained in the preview.

Use metric source quantities. Grams do not automatically mean cups: a cup equivalent needs a known weight for that particular ingredient. The existing grams-per-cup and tested US-override fields are unchanged. Check both unit views on the public page after editing measurements.

MEDIA & PREVIEW

Check it as you write.

Paste a YouTube HTTPS link or video ID. The video field shows its thumbnail and a Check video link. The optional Use clean link button removes sharing parameters; it does not change the video ID. Invalid link formats are flagged before saving. A thumbnail does not prove that a video is public or embeddable.

The preview includes ingredients, steps, yield, times, picture or video thumbnail and extra notes. Choose Narrow for a smaller reading column. This is a content preview, not an exact mobile-device simulation.

Open Before publishing for reminders about ingredients, empty steps, video links and optional details. Suggestions do not rewrite a recipe, and the checklist is not a food-safety review or a deployment check.

Thumbnails load from YouTube's image service in the editor. No video starts playing automatically.

PUBLISHING

Saved is not the same as live.

Publish saves the recipe in GitHub. Visible on website controls whether the next website build includes it. Keep that switch off while saving an unfinished recipe; turn it on and publish when ready.

The new save notification confirms only that Decap reported a successful save. The publishing workflow still has to finish. Use Kitchen tools → Check publishing build to open GitHub Actions and check the outcome.

Publish and create new saves the current recipe and starts a blank form. Publish and duplicate saves it and starts a copy. Neither publishes the new second recipe until it is saved separately.

To remove a recipe from the website without deleting it, turn visibility off and publish. The existing delete permission is unchanged by this update. Where deletion is enabled, use Decap's delete action and confirm it.

Hidden does not mean private: content and its previous revisions can still be read in a public GitHub repository. This update adds no autosave and no private-draft storage. Save your work before closing the editor.

WHEN YOU NEED A HAND

Tools without losing your place.

The small Kitchen tools menu opens the helper, guide, website and build page in a separate tab. It does not close or modify the recipe you are editing.

What if the enhanced editor does not load?

Open Basic editor mode. It uses the original field configuration and original preview. Your Cloudflare login, repository access and content are the same. Fraction entry is an enhancement: in basic mode enter decimals such as 0.5.

Why is my recipe not updated on the public site?

A failed or unfinished build can leave the previous site online. Check the publishing workflow rather than repeatedly publishing. A hidden recipe is intentionally absent from the built website.

What did this update change?

Only the editor's front-end files. Your stored recipes, CMS YAML settings, Cloudflare Worker, secrets, branch, permissions, public styles and Python builder were not changed. Labels, order, category filters and two field widgets are enhanced in browser memory.

Built on Decap CMS. Sign out on shared computers. Never paste GitHub secrets or tokens into recipe fields.
